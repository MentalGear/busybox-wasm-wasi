Usage

This is an interactive BusyBox ash shell running in WebAssembly with Wasmer SDK 0.6.x.

  • Type commands and press Enter to execute
  • Use arrow keys for command history (within session)
  • Try: echo Hello, date, ls, pwd

Limitations

  • Pipelines within shell don't work (use separate commands)
  • No persistent filesystem between page reloads
  • No networking commands

Compatibility

This demo uses @wasmer/sdk@0.6.x, compatible with Wasmer Runtime 6.x.
